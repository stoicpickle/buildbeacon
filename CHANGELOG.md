# Changelog

All notable changes to BuildBeacon are documented here. This project follows semantic versioning once release tags begin.

## 0.1.0 — 2026-07-31

Initial public experiment:

- deterministic dCBOR build-receipt schema and strict decoder;
- domain-separated Ed25519 signed envelope with separate trust state;
- BBP/1 bounded random-linear erasure transport with systematic and repair QR frames;
- browser Transmit, Recover, and Inspect workflows;
- local camera and uploaded-video decoding;
- reproducible six-second H.264 pixel-recovery fixture;
- local CLI for key generation, receipt creation, verification, simulation, and QR-frame export;
- protocol, threat-model, test-matrix, CI, Pages, and security documentation.
